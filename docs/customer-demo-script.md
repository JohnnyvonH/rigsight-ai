# Customer Demo Script

## Goal

Show an engineering test team how RigSight AI moves from telemetry to detection, review, and reporting.

## Flow

1. Start on Overview and describe fleet health, active runs, high alerts, and review backlog.
2. Enable demo mode only if a reset is needed, then seed the baseline or fault-heavy scenario.
3. Open Telemetry and switch between temperature, vibration, current, and compare views.
4. Open Alerts, filter by high severity and rules or ML, then expand an alert for explainability.
5. Open Review, assign a follow-up owner, and mark an alert confirmed or needs follow-up.
6. Open Runs and generate the HTML report, then mention JSON export for integrations.
7. Open System and explain clean-room data, pilot limits, readiness, metrics, and deployment path.
