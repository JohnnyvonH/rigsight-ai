# Clean-Room Statement

RigSight AI is a public portfolio project built from scratch using synthetic telemetry, generic engineering examples, and public/open-source libraries.

The project does not use or reproduce:

- employer code
- employer data
- employer screenshots
- employer architecture diagrams
- employer naming conventions
- internal process details
- confidential test data or issue examples

All sensor values, test phases, fault modes, alerts, labels, and camera experiments are synthetic or generated from personally controlled local devices such as a webcam.

The goal is to demonstrate transferable software engineering skills around telemetry ingestion, anomaly detection, dashboards, alert triage, and human review workflows without exposing private or proprietary information.
