# RigSight AI Sales Demo Pack

This folder contains the first-pass sales collateral for a guided RigSight AI
pilot demo.

## Files

- `rigsight-sales-demo-deck.pptx` - PowerPoint deck for a 5-10 minute sales
  walkthrough.
- `demo-script.md` - Presenter script and discovery questions to build upon.
- `public-demo-deployment-plan.md` - Plan for hosting a private public demo.
- `rigsight-pilot-import-template.csv` - Sanitized CSV template for import
  demos.
- `sample-run-report.pdf` - Sample PDF report generated from the local backend.
- `screenshots/` - Full-system route screenshots used by the deck.
- `deck-preview/` - Rendered slide previews and contact sheet for QA.

## Suggested Use

1. Open the PowerPoint deck.
2. Use `demo-script.md` as the talk track.
3. Keep the CSV template and sample PDF ready during the Runs page portion.
4. Use `public-demo-deployment-plan.md` to create a hosted demo link before
   outreach.

## Demo Story

RigSight helps validation teams move from raw test-run telemetry to reviewed
evidence: import sanitized data, tune thresholds, explain alerts, record review
decisions, and export a report.
